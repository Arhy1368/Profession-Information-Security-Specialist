#1. Развертывание — импорт OVA, настройка сети, вход в систему.

Все команды, которые вы выполняли:

1.1 Импорт OVA

В VirtualBox выполнен импорт OVA-образа с настройками по умолчанию. После импорта добавлен второй сетевой адаптер с типом «Внутренняя сеть» и именем intnet.

1.2 Первичный вход 🌐

Вход в операционную систему выполнен под учетной записью system с паролем system. При первом входе пароль был изменен.

💡Рекомендация:

Если настроить файрвол так, чтобы он разрешал доступ к порту 8888 только с определённых IP-адресов,

то доступ к сайту получат только те машины, которые вы укажете. Остальные не смогут подключиться.

Вы создаёте правило: «Разрешить подключения к порту 8888 только с IP-адреса 192.168.0.2 (Kali) и,

возможно, с IP вашего хоста». Все остальные подключения будут отклонены.

Настройка (альтернатива sudo ufw disable)
Вместо полного отключения файрвола вы можете добавить правило:

bash
# Разрешить доступ к порту 8888 только с IP 192.168.0.2 (Kali)
    sudo ufw allow from 192.168.0.2 to any port 8888 proto tcp

# Если нужно добавить ещё и хост (например, 192.168.1.100)
    sudo ufw allow from 192.168.1.100 to any port 8888 proto tcp

# Проверить, что порт разрешён
    sudo ufw status

Это называется ограничением доступа по IP-адресу или белым списком (whitelist).

или «Защита через ограничение доступа» (Network Access Control).

Вы одновременно:

✅ Повышаете защищённость — закрываете порт для всех, кроме доверенных IP.

🔒 Ограничиваете круг пользователей — подключаться смогут только те, кто в белом списке.
