📌 Описание проекта

В рамках итоговой работы по модулю «Защищённый контур» был проведён 
анализ защищённости корпоративного приложения, предназначенного для обмена 
корпоративной информацией, включая персональные данные клиентов и коммерческую тайну.

Заказчик: Компания Х  
Разработчик: Неизвестен (OVA-образ поставлен «из коробки»)  
Исполнитель: Паничевский А.В. ученик  
Цель: Проверка реальной защищённости приложения и выявление 
несоответствий требованиям нормативных документов (ФСТЭК №21).
